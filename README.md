# Student Management System

A console-based Student Management System built using Java.

## Technologies Used

- Java
- OOP
- Collections
- File Handling
- JDBC
- MySQL

## Project Evolution

This project was developed in three stages:

1. **Collections** — Student data managed using Java Collections.
2. **File Handling** — Student data persisted using files.
3. **JDBC + MySQL** — Student data stored and managed using a MySQL database through JDBC.
## Features

- Add student
- View all students
- Search student
- Update student
- Delete student
- Input validation
- Exception handling

## Project Structure

- `Collections/` — Collections-based version
- `FileHandling/` — File handling version
- `JDBC/` — JDBC + MySQL version
